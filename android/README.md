ANGEL'S LIFE Android prototype
================================
Run GitHub Actions workflow 'Android prototype APK' to compile a debug APK. The prototype must only be used with synthetic test data. No patient records, identifiers, or signatures should be entered. The HTML currently lives in repository root and is packaged as a local WebView asset. This is not a production clinical application. Official logo asset is still missing. PDF printing is not yet implemented inside Android WebView; the browser print button requires a native print bridge before release.
